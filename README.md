# Noob Incremental Wiki

Unofficial fan-made Noob Incremental wiki for codes, beginner routes, upgrades, runes, prestige, tickets, potions, community safety notes, and FAQ.

## Development

```bash
npm install
npm run dev
```

Open `http://127.0.0.1:3000`.

## Build

```bash
npm run build
```

The project uses Next.js static export. The Cloudflare Pages output directory is `out`.

## Cloudflare Pages

- Build command: `npm run build`
- Output directory: `out`
- Node version: use the default current Node.js runtime or Node 20+
